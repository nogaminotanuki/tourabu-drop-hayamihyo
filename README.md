# 刀剣男士ドロップ早見表 — 全32合戦場 公開版

GitHub Pagesへそのまま置ける静的Webツールです。

- 過去合戦場 1-1〜8-4 全32合戦場
- 合戦場 → 刀剣男士
- 刀剣男士 → 合戦場の逆引き
- 通常 / ボス / 検非違使
- 刀種フィルター
- 刀帳番号順
- 検非違使は合戦場結果の最下部で折りたたみ
- 刀剣男士逆引きでは対象のみ紫ラベル

`data.json` を更新すれば両方向の表示へ反映されます。

2026年3月24日のドロップ変更後データを、2026年9月10日にゲーム内「指南」と照合済みです。
公開画面の出典表示は公式情報のみです。攻略サイト・Wikiはダブルチェックの補助資料として使用しています。

## データ更新

- ドロップ情報を変更する場合は `data.json` のみを更新します。
- `battlefields`・`touken`・`drops`・`kebiishiToukenIds` を単一のデータ源として、両検索画面を生成します。
- 更新時はゲーム内「指南」を優先し、`meta.verifiedAt` も更新してください。

- 結果カードはPCで6列、タブレットで3〜4列、スマホで2列

「通常」「ボス」「検非違使」は合戦場色とは独立した文字付きラベルを維持します。
